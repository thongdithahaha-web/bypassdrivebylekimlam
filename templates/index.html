💡 Hướng dẫn

1. Cookies.txt

  1. Cài extension Get cookies.txt LOCALLY trên Chrome.
  2. Đăng nhập drive.google.com.
  3. Export cookies cho domain google.com, upload lên tool.

2. Service Account (khuyến nghị – không bị quota)

  1. Vào Google Cloud Console → tạo Service Account.
  2. Tải file JSON key về máy.
  3. Share file/thư mục Drive cho email xxx@xxx.iam.gserviceaccount.com.
  4. Upload file JSON lên tool.
